# Start here

This is the Reliability, Diagnostics, and Fault-Tolerant Systems interactive MATLAB track. Run
`./bin/learn status`, then `./bin/learn start`. P01 is the implemented reference and P02 is the
implemented hazard-to-survival lesson; P03-P24 remain intentional scaffolds mapped one-to-one to
Portfolio Control batches. A learner session follows read → visualize → move one lever → visualize
the change → read/explain, then a broken case, checks, and teach-back.

Use `docs/CURRICULUM_AUDIT.md` for the complete phase and batch map.
