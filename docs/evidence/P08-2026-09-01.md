## Model contract and independent reference values

P08 preserves P07's fixed 1000-hour, no-repair cooling boundary and independent `S`, `A`, and `B`
basic-event assumption. P06's modes and P05/P07 Boolean logic become four disjoint loss-bearing
scenarios plus one all-working outcome:

```text
P(S fails)                         = q_S                         = 0.00500
P(S up; A and B fail)              = (1-q_S)q_A q_B              = 0.00995
P(S and A up; B fails)             = (1-q_S)(1-q_A)q_B           = 0.08955
P(S and B up; A fails)             = (1-q_S)q_A(1-q_B)           = 0.08955
P(S, A, and B up)                  = (1-q_S)(1-q_A)(1-q_B)       = 0.80595
```

Only the first two outcomes fail the P07 mission, so system failure is `0.01495`. The last three
outcomes retain mission success, so system reliability is `0.98505`; the two single-pump outcomes
are degraded successes that can carry repair or degraded-operation cost. Expected economic loss
therefore must not be interpreted as mission-failure probability.

The first four scenario consequences are synthetic `[120,100,8,12]` kUSD per occurrence. Their
common-unit expected-loss contributions are:

```text
[0.00500,0.00995,0.08955,0.08955] .* [120,100,8,12]
    = [0.6000,0.9950,0.7164,1.0746] kUSD/mission
total = 3.3860 kUSD/mission
priority = [A only, A&B, B only, S]
```

Independent Python arithmetic retained in the focused tests covers:

- five-outcome probability closure and the exact P07 ledger;
- the P07 partition of the first two mission-failure outcomes from the last three success outcomes,
  including `q=[0,1,0]`, where Pump A fails, Pump B preserves certain mission success, and the
  A-only scenario still carries `12` kUSD/mission of loss;
- each baseline `P*C` identity, total, risk share, rank, and `0.4746` risk spread;
- shared-supply sweep `q_S=[0,0.005,0.01,0.02,0.05]`, total expected loss

A subsequent independent review found one material physical-interpretation defect: learner-facing
text called all four priced outcomes failure scenarios even though P07 defines only shared-supply
failure and supply-up dual-pump failure as mission failures. The B-only and A-only outcomes retain
mission success through the companion pump; they are degraded successes that can still carry cost.
Conflating these categories could teach a learner that component failure, economic loss, and mission
failure are interchangeable.

sweep, and rank unchanged. `model.m` now exposes P07 system failure `0.01495` and system reliability
`0.98505`; experiment and interactive summaries show that partition; and learner text consistently

`0`, the all-components-working probability is `0`, and A-only expected loss is `12` kUSD/mission.
