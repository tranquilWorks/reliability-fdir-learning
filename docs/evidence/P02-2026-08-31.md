## Model contract and independent reference values

For base hazard `lambda0 >= 0`, dimensionless post-change multiplier `m >= 0`, change
time `0 <= tau <= T`, and a nonrepairable population with a known shared exposure:

```text
h(t) = lambda0                  for t < tau
h(t) = lambda0*m                for t >= tau
H(t) = lambda0*min(t,tau) + lambda0*m*max(t-tau,0)
S(t) = exp(-H(t))
```

The hazard may jump at `tau`; cumulative hazard and survival remain continuous. The model excludes
repair and unmodeled population heterogeneity.

Python reference arithmetic retained by `test_reference_values_and_limiting_cases_are_independently_known`:

- Baseline `lambda0=2e-4 /h, m=1, T=3000 h`: `H(T)=0.6`,
  `S(T)=0.5488116360940264`.
- Changed case `lambda0=2e-4 /h, m=4, tau=1000 h, T=3000 h`: `H(T)=1.8`,
  `S(T)=0.16529888822158653`.
- Broken case `lambda0=1e-3 /h, m=3, tau=500 h, T=2000 h`: `H(T)=5`,
  exact `S(T)=0.006737946999085467`, invalid linear approximation `1-H=-4`.
- Zero cumulative hazard gives `S=1`.
- Failure probability uses `-expm1(-H)`, retaining a positive value near `1e-20` where direct
  subtraction `1-exp(-H)` would round to zero.

These values check the intended equations independently of the MATLAB source but do not prove that
MATLAB evaluated the source identically.
