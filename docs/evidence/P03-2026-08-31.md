## Model contract and independent reference values

For failure rate `lambda >= 0` in failures/hour, mean repair time `r > 0` hours, repair rate
`mu=1/r` repairs/hour, and initial availability `A(0)` in `[0,1]`:

```text
dA/dt = mu*(1-A) - lambda*A
A_inf = mu/(lambda+mu) = 1/(1+lambda*r)
U_inf = lambda/(lambda+mu)
A(t) = A_inf + (A(0)-A_inf)*exp(-(lambda+mu)*t)
p(t) = -expm1(-(lambda+mu)*t), d(t) = exp(-(lambda+mu)*t)
A(t) = A_inf*p(t) + A(0)*d(t)
U(t) = U_inf*p(t) + U(0)*d(t)
```

The governing operation is visible base-MATLAB arithmetic. The deterministic probabilities model
an exponential two-state process with immediate repair coverage; they are not a sampled outage
timeline or observed operational data.

The independent review uses NASA's documented distinction between
[point availability and average mission availability](https://extapps.ksc.nasa.gov/Reliability/Documents/170508_FORMULAS_Inherent_Availability_and_Reliability_with_Constant_Failure_and_Repair_Rates.pdf).
P03 exposes the last point value as `endpointAvailability` and does not claim to compute
interval-average mission availability.

Independent Python reference arithmetic retained by
`test_reference_values_limits_and_cancellation_are_independently_known`:

- Baseline `lambda=0.001 /h`, `MTTR=10 h`, `T=100 h`, initially up:
  `mu=0.1 /h`, `A_inf=0.9900990099009901`, `U_inf=0.009900990099009901`,
  `A(T)=0.9900994166292596`, relaxation time `9.900990099009901 h`, and steady
  equivalent downtime `86.73267326732673 h/8760 h`.
- With the same positive rates and `T=100 h`, an initially down item has
  `A(T)=0.9900583370740343`. The initially up and down endpoints remain on opposite sides of the
  same `A_inf`, and their initial net flows point toward that balance.
- Failure sweep `lambda=[0.0005, 0.001, 0.005] /h` with `MTTR=10 h` gives
  `A_inf=[0.9950248756218906, 0.9900990099009901, 0.9523809523809523]`.
- MTTR sweep `[2, 10, 40] h` with `lambda=0.001 /h` gives
  `A_inf=[0.998003992015968, 0.9900990099009901, 0.9615384615384615]` and steady
  equivalent downtime `[17.48502994011976, 86.73267326732673, 336.9230769230769] h/8760 h`.
- Equal failure and repair rates give `A_inf=0.5`; zero failure with an initially up item gives
  `A(t)=1`.
- At the admitted lower horizon `T=1e-6 h` with `lambda=1e-12 /h`, the stable `expm1` path
  retains positive unavailability `9.999999500000018e-19` instead of losing it to subtraction.
- At `lambda=1e6 /h`, `MTTR=1e9 h`, and `T=100 h`, the exponential remainder is zero in
  double precision. The retained mixture gives the exact computed equilibrium availability
  `9.999999999999991e-16`; the subtraction-prone form it replaced had relative error
  `7.99e-4`. Endpoint failure and repair flow have zero relative gap in the independent probe.
- The symmetric initially-down, fast-repair extreme retains a tiny nonzero equilibrium
  unavailability rather than losing it when recovery is complete.
- Broken case `T=5000 h`: no-first-failure reliability is
  `exp(-5)=0.006737946999085467`, while repairable point availability is
  `0.9900990099009901` to retained precision.

These reference values check the intended equations independently of the MATLAB source but do not
prove that MATLAB evaluated the source identically.
